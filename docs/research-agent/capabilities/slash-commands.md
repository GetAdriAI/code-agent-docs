# Slash Commands

The purpose of Slash commands is to trigger in-built prompt templates in SAP Research Agent. They are prefixed with `/`.

One such slash command is `/migrate`. It streamlines one of the most complex SAP journeys: migrating from SAP ECC 6.0 to SAP S/4HANA 2023.

With a single command, you get:

- Pre-built prompt templates optimized for migration use cases
- Auto-selected connected SAP systems for both ECC 6.0 and S/4HANA 2023
- Instant search across a combined set of 45M+ SAP standard objects

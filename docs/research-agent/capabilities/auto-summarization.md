# Auto Summarization

Adri AI's SAP Research Agent automatically summarizes the conversation history when the context window reaches capacity. This allows extended sessions to continue without losing essential information.

## How It Works

1. The agent monitors context window usage during your session
2. When the limit is reached, the agent compresses the conversation into a summary
3. The session continues with the summary as context, freeing up space for new interactions

## Important Considerations

- **Information condensation**: The agent prioritizes key findings and decisions, but may condense details you consider important
- **Reiterate when needed**: If the agent seems to have forgotten specific context, restate the relevant information
- **Long research sessions**: For extended investigations, consider periodically noting key findings in your own records

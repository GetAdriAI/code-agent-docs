## What is a project?

A project is your workspace in Adri AI.
Everything you do is organized inside a project.

- SI firms can create one project per client.
- SAP customers can create one project per geography, business unit, or rollout.
- Each project is isolated from other projects.
- You can connect an unlimited number of SAP systems inside one project.

## Open Project Settings

Use these steps to open **Project Settings**.
Project Settings is where you manage SAP connections and project-level setup.

> In every screenshot, the red box shows exactly where to focus.

1. After logging in, go to <a href={ADRI_URLS.projects}>getadri.ai/projects</a>.
2. In the **Projects** list, click **Open** for your project.

![Click Open for your project](/img/project-management/open-project/1.png)

3. In the app selection dialog, choose **Project Settings** under **Project Management**.

![Select Project Settings in the app picker](/img/project-management/open-project/2.png)

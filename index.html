Welcome to Adri AI Docs

If you are new to Adri AI, start here. These docs show you how to set up your project, connect SAP, use Adri with coding agents like Codex/Cline/Claude Code, and run your first useful prompts.

What to expect?​

  1. Project Management first
    Learn what a project is, open the correct project, and create a new one: Open a Project and Create a Project.

  2. Connect SAP systems cleanly
    Follow step-by-step guides to connect SAP systems in Adri AI: Connect Your SAP System and VPN Users. If your SAP system is only reachable through VPN, we also show how to install and use Adri Relay (the small desktop app that securely bridges that VPN-only access).

  3. Use Adri MCP Server with your coding agent
    Install your coding tools first: Install VS Code and Agent Tools.
    Then set up Adri MCP Server using Setup (Claude Code) or Setup (Codex).
    The same MCP server works with Codex, Cline, Claude Code, and other MCP-compatible agents. This includes creating .mcp.json, signing in, and approving tools for all projects. For advanced SAP-side capabilities, you can also install Setup Enabler Framework in about 3-5 minutes per system. Check what is currently supported in MCP Capabilities.

  4. Get started with Code Agent
    Use the full beginner onboarding flow in Adri Code Agent: Complete Onboarding Guide.

  5. Run practical SAP use cases
    Start with Read and Write SAP Configuration, Clean Core Assessment, and Use Debugger to Find BAdI Automatically to see full prompt-to-result workflows, including IMG Extraction, fit-to-X planning, and runtime debugger discovery.

  6. Run advanced SAP research workflows
    Use SAP Research Agent for object discovery, system validation, and research workflows.

  7. Cover architecture, concepts, and references
    Explore Deploying Adri in Enterprise, AI Concepts, Glossary, and Comparisons.

Let's get started!

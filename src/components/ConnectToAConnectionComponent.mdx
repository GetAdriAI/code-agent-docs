## Connect a SAP system in Adri Code Agent

Use this guide after your SAP connection is already created.

> In every screenshot, the red box shows exactly where to focus.

1. Open <a href={ADRI_URLS.code}>code.getadri.ai</a> and click **Systems**.

![Click Systems in Adri Code](/img/connect-to-sap-system-code-agent/1.png)

2. In the systems panel, turn on the switch for the SAP connection you want to use.

![Enable a SAP connection switch](/img/connect-to-sap-system-code-agent/2.png)

3. Wait until the switch turns green. This means the system is connected and ready.

![Verify the switch is green](/img/connect-to-sap-system-code-agent/3.png)
